# Servatos Apparel Website

Welcome to the official repository for **Servatos Apparel**! This is a responsive, front-end web application built to showcase an apparel collection, provide information about the brand, and offer an interactive contact and inquiry form.

---

## 🚀 Project Overview

This project is structured using modern HTML5, styled with responsive CSS3 (utilizing Flexbox and Media Queries), and enhanced with interactive JavaScript DOM manipulation.

### **File Structure**
*   `index.html` — The main structure of the web page containing semantic HTML elements, navigation links, product listings, and a contact form.
*   `style.css` — The styling sheet responsible for the layout, color schemes, hover transitions, and mobile responsiveness.
*   `script.js` — The JavaScript file handling console outputs, user variable declarations, dynamic DOM element manipulation, and click event listeners.

---

## 🛠️ Features & Functionality

*   **Responsive Navigation Bar:** Features quick links to jump straight to the About, Collection, and Contact sections.
*   **Featured Collection Showcase:** Displays highlighted apparel items (Classic Hoodie, Classic Pants, Classic Hat) with respective pricing in PHP.
*   **Interactive Contact Form:** Allows users to submit inquiries with name, email, and message inputs.
*   **Dynamic DOM Manipulation (JavaScript):** 
    *   Programmatically updates the main website heading (`<h1>`) text and styles on load.
    *   Includes a click event listener on the main heading that changes its color and logs actions to the browser console.
*   **Responsive Design:** Implements CSS media queries to adapt layout elements cleanly across desktop and smaller mobile screens.

---

## 💻 Getting Started / How to Run

To view and test this project locally on your machine, follow these simple steps:

1. **Clone or Download** the repository to your local computer.
2. Ensure all three files (`index.html`, `style.css`, and `script.js`) are saved in the **same directory/folder**.
3. Open `index.html` using any modern web browser (such as Google Chrome, Mozilla Firefox, or Microsoft Edge).
4. Open your browser's Developer Tools (Press `F12` or right-click and select **Inspect**, then go to the **Console** tab) to view the JavaScript log outputs.

---

## 🎨 Customization

*   **Changing Styles:** Modify `style.css` to adjust background colors, fonts, section padding, or button hover effects.
*   **Updating Products:** Edit the `<section id="collection">` block inside `index.html` to add, remove, or change product names and prices.
*   **JavaScript Tweaks:** Update user details or event behaviors inside `script.js`.
